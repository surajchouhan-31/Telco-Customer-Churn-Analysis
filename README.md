# Telco Customer Churn Analysis Dashboard

# Project Overview
This project analyzes customer churn behavior in a telecom company using Excel.

The dashboard helps identify factors affecting customer retention and customer loss.

# Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Dashboard Design

# Key KPIs
- Total Customers
- Churn Customers
- Churn Rate
- Retention Rate

# Analysis Performed
- Contract Churn Analysis
- Internet Service Churn Analysis
- Tenure Churn Analysis
- Monthly Charges Churn Analysis
- Payment Method Churn Analysis

# Key Insights
- Month-to-month customers have the highest churn.
- Fiber optic users show higher churn.
- Customers with high monthly charges churn more.
- Long-term customers are retained better.
- Electronic check users have higher churn rates.

# Outcome
The dashboard provides business insights that can help improve customer retention strategies.
